# Shopora - Modern E-Commerce Website

Shopora is a modern, responsive e-commerce website built as an internship project.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage
- Git & GitHub
- GitHub Pages

## Features

- Responsive navigation
- Mobile-friendly layout
- Hero section
- Product categories
- 15 products
- Product search
- Category filtering
- Price filtering
- Product sorting
- Product details page
- Related products
- Add to Cart
- Increase/decrease quantity
- Remove from Cart
- Cart item counter
- LocalStorage cart persistence
- Checkout form
- Checkout validation
- Payment method selection
- Order summary
- Order confirmation
- Customer testimonials
- Newsletter section
- Responsive product cards
- Hover effects
- Responsive mobile navigation

## Pages

1. Home
2. Products
3. Product Details
4. Shopping Cart
5. Checkout
6. Order Confirmation

## Deployment

The project can be deployed using GitHub Pages.
